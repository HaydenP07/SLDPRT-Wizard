<h1 align="center">SLDPRT Wizard</h1>

## Overview

SLDPRT Wizard is a Windows desktop application designed to simplify and automate repetitive SolidWorks workflows. It allows users to batch process CAD files, generate drawings, and export models through an intuitive graphical interface.

Built for engineers, designers, and CAD professionals, SLDPRT Wizard helps reduce manual file handling and streamline common SolidWorks tasks.

## Features

- Batch process multiple SolidWorks files
- Convert SolidWorks parts and assemblies to different export formats
- Automatically generate engineering drawings
- Support for customizable drawing templates
- Queue-based file management
- User-friendly graphical interface
- Automated SolidWorks integration

## Requirements

- Windows operating system
- SolidWorks installation required
- Compatible SolidWorks version recommended: 2025 (Other modern versions likely work, but only 2025 has been tested)

## Installation

1. Download the latest release from the GitHub Releases page.
2. Extract the downloaded file.
3. Run `SLDPRT_Wizard.exe`.
4. Follow the instructions within the application.

No Python installation is required.

## Usage

1. Select the files you would like to process.
2. Choose the desired export type or drawing template.
3. Select an output location.
4. Start the conversion process.

SLDPRT Wizard will automatically communicate with SolidWorks to complete the requested operations.
